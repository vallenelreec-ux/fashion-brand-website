# Fashion Brand Website

A mobile-first portfolio and customer-contact website for a Moroccan couture and embroidery business.

## Project goals

- Present genuine examples of traditional and modern sewing, tailoring, and embroidery.
- Showcase work for women and children, with a focus on jellabas.
- Explain custom-design requests and ready-made pieces when available.
- Direct visitors to WhatsApp for inquiries and orders.
- Link to Instagram and Facebook for new work and updates.
